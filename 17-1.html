17-1 · JavaScript 数据交换

JSON：JavaScript Object Notation

JSON 是一种轻量级的数据交换格式，独立于语言、易于阅读和解析，是前后端传输数据的事实标准。

一、语法规则与数据类型

{ "name": "张海玉", // 键必须用双引号 "age": 21, // 数字 "isStudent": true, // 布尔 "hobbies": ["网页设计", "前端"], // 数组 "school": { // 嵌套对象 "name": "大连东软信息学院" }, "remark": null // 空值 }
字符串"..." 数字21 布尔true / false 空值null 数组[ ] 对象{ }

注意：JSON 不支持函数、undefined、单引号键名和注释。

二、JSON 与 JS 对象的区别

对比项JSONJS 对象
键名必须双引号单双引号或裸键均可
值类型不含函数 / undefined任意类型
注释不允许// 与 /* */ 均可
结尾逗号不允许允许
本质字符串（文本格式）内存中的数据结构

三、两个核心方法：parse 与 stringify

// 字符串 → 对象（反序列化） var obj = JSON.parse('{"name":"张海玉"}'); // 对象 → 字符串（序列化） var str = JSON.stringify({ name: "张海玉" }, null, 2);

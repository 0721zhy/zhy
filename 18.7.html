Three.js 核心概念

  • Scene + Camera + Renderer三维世界三件套：Scene 装物体，PerspectiveCamera 定义视角，WebGLRenderer 把画面画到 canvas 上。
  • Mesh + MaterialBoxGeometry / CylinderGeometry 定义形状，MeshLambertMaterial 定义受光表面，合起来就是可见的立体网格。
  • LightAmbientLight 环境光打底 + DirectionalLight 方向光制造明暗立体感，3D 图表"好看"一半靠打光。
  • 交互三件套拖拽改 scene.rotation、滚轮改 camera 位置、Raycaster 射线拾算鼠标指向哪个 Mesh——不依赖 OrbitControls 也能实现。

3D 柱状图核心代码

// 场景三件套 var zhyScene = new THREE.Scene(); var zhyCamera = new THREE.PerspectiveCamera(45, 宽/高, 0.1, 1000); var zhyRenderer = new THREE.WebGLRenderer({ antialias: true }); // 一根柱子 = 形状 + 材质 + 网格 var zhyGeo = new THREE.BoxGeometry(3, zhyH, 3); var zhyMat = new THREE.MeshLambertMaterial({ color: zhyColor }); var zhyMesh = new THREE.Mesh(zhyGeo, zhyMat); zhyMesh.position.set(x, zhyH / 2, z); // 底面贴地 zhyScene.add(zhyMesh); // 渲染循环：每帧绘制一次 (function zhyLoop() { requestAnimationFrame(zhyLoop); zhyRenderer.render(zhyScene, zhyCamera); })();

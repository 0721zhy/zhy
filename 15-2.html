JS 程序结构 · 循环与条件

程序三大结构：顺序、条件（分支）、循环。本页用 4 个可交互小演示展示 if/else、switch、for、while 的实际用法，所有结果同时输出到 F12 控制台。

条件判断 · if / else if / else

输入一个 0 ~ 100 的分数，程序按区间链式判断，输出等级：

if (score >= 90) grade = '优秀'; else if (score >= 80) grade = '良好'; else if (score >= 70) grade = '中等'; else if (score >= 60) grade = '及格'; else grade = '不及格';

条件判断 · switch 多分支

选择数字 1 ~ 7，switch 按分支精确匹配，注意 break 的作用：

switch (day) { case 6: case 7: name = '周末'; break; // 落空共享分支 case 1: name = '星期一'; break; // … default: name = '输入无效'; }
等待选择…

循环 · for 打印九九乘法表

双重 for 循环：外层控制行 i = 1~9，内层控制列 j = 1~i：

for (var i = 1; i <= 9; i++) { for (var j = 1; j <= i; j++) { print(j + '×' + i + '=' + (i * j)); } }

循环 · for 求和 与 while 倒计时

for 适合已知次数；while 适合"满足条件就继续"的未知次数场景：

var sum = 0; for (var n = 1; n <= 100; n++) sum += n; // → 5050 var t = 5; while (t > 0) { print(t); t--; } // 倒计时

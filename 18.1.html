Canvas 弹跳粒子球动画

使用 <canvas> 2D 上下文与 requestAnimationFrame 逐帧绘制：每颗小球有位置、速度、颜色，受重力加速、与地面/墙壁碰撞反弹，并带有尾迹拖尾效果。点击画布可在点击处发射一颗新球。

二、核心代码

// 动画主循环：清屏 → 更新物理 → 绘制 → 请求下一帧 function zhyLoop() { zhyCtx.fillStyle = 'rgba(20,32,44,.25)'; // 半透明覆盖形成拖尾 zhyCtx.fillRect(0, 0, zhyW, zhyH); zhyBalls.forEach(function (zhyB) { zhyB.vy += zhyGravity; // 重力加速 zhyB.x += zhyB.vx; // 更新位置 zhyB.y += zhyB.vy; if (zhyB.y + zhyB.r > zhyH) { // 撞地反弹并损耗能量 zhyB.vy *= -0.85; } zhyCtx.beginPath(); zhyCtx.arc(zhyB.x, zhyB.y, zhyB.r, 0, Math.PI * 2); zhyCtx.fill(); }); requestAnimationFrame(zhyLoop); // 与屏幕刷新率同步 }

三、Canvas 动画要点

  • getContext('2d')获取 2D 绘图上下文，所有绘制都通过它完成：arc 画圆、fillRect 填充矩形等。
  • requestAnimationFrame浏览器自带的动画帧 API，与屏幕刷新率（约 60 次/秒）同步，比 setInterval 更流畅省电。
  • 清屏技巧不用 clearRect 而是用半透明矩形覆盖，上一帧的残影逐渐变淡，形成"拖尾"效果。
  • 物理模拟速度 + 重力加速度逐帧积分；碰撞时速度取反并乘 0.85 的能量损耗系数，小球越弹越低。
说明：本页全部使用原生 Canvas 2D API，无任何第三方动画库；画布尺寸随窗口自适应，并按 devicePixelRatio 做高清屏适配。

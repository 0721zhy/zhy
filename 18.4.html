18-4 · ECharts 数据可视化

ECharts 两个数据图表

ECharts 是百度开源、现由 Apache 基金会托管的可视化图表库（示例代码参考 echarts.apache.org）。为符合本站"资源全部本地化"的要求，官方 CDN 上的 echarts.min.js 与 SVG 地图资产已下载到 cdn/ 目录本地引用。本页包含两个图：柱状 + 折线混合图与基于 SVG 的地理地图。

图一 · 2026 年销售趋势（柱状图 + 折线图）

柱形展示每月销售额，折线展示同比增长率，双 Y 轴呈现量级不同的两类指标。

试试：把鼠标悬停在柱子上查看数据详情；点击顶部图例可隐藏/显示对应系列。

图二 · 地图（SVG）· 古西西里部落势力图

geo 组件直接加载 SVG 地图（官方 GEO SVG Map 示例同款西西里地形图）。地图上的 route1 / route2 按钮可以点击：选中后对应部落区域会高亮，并弹出介绍气泡。

试试：点击顶部 route1 / route2 按钮切换高亮区域；地图支持鼠标滚轮缩放与拖拽漫游（roam）。

两种图表对比

对比项柱状 + 折线混合图SVG 地图（geo 组件）
擅长表达趋势与对比：随时间变化的数量关系地理与空间：区域划分、位置与路线
数据维度类目轴（月份）× 双数值轴（金额、百分比）SVG 视口坐标（x, y）× 区域名称
关键配置series 的 type: 'bar' / 'line'，yAxis 配两个registerMap 注册 SVG → geo.map 引用 → regions 按名设样式
交互特性图例切换系列、tooltip 十字准星区域选中高亮、tooltip 气泡、滚轮缩放拖拽漫游

ECharts 使用三步核心代码

<!-- 1. 引入库（本页已本地化：cdn/echarts.min.js） --> <script src="cdn/echarts.min.js"></script> // 2. 初始化：传入 DOM 容器（容器必须有宽高） var zhyChart = echarts.init(document.querySelector('[data-zhy-chart-bar]')); // 3. setOption 配置数据与样式 zhyChart.setOption({ tooltip: { trigger: 'axis' }, // 悬停提示 legend: { data: ['销售额', '同比增长率'] }, xAxis: { type: 'category', data: ['1月', '2月', ...] }, yAxis: [{ type: 'value' }, { type: 'value' }], // 双 Y 轴 series: [ { name: '销售额', type: 'bar', data: [...] }, { name: '同比增长率', type: 'line', yAxisIndex: 1, smooth: true } ] }); // 窗口尺寸变化时自适应 window.addEventListener('resize', function () { zhyChart.resize(); });
说明：echarts.min.js（v5.5.1，约 1MB）与 SVG 地图资产均来自官方并已本地化到 cdn/ 目录，页面离线也能正常渲染；柱线图数据为教学模拟数据。

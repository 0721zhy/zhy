JavaScript 对象：属性、方法与内置对象

对象是"属性 + 方法"的集合。本页以一个学生对象为例，演示创建、访问、增删改查、遍历以及 Math / Date 内置对象。

一、创建对象的三种方式

// ① 对象字面量（最常用） var zhyStudent = { name: '张海玉', zhyStudentId: '20230101', study: function () { return '正在学习 JS 对象'; } }; // ② new Object() var zhyBook = new Object(); zhyBook.title = '高级网页设计'; // ③ 自定义构造函数（可批量生产） function ZhyLaptop(brand, ram) { this.brand = brand; this.ram = ram; } var zhyPc = new ZhyLaptop('Lenovo', 16);

zhyStudent.name // 点语法：常用 zhyStudent['name'] // 方括号：属性名是字符串 zhyStudent[zhyKeyName] // 方括号：可以用变量动态取 zhyStudent.study() // 调用方法（this 指向对象自身）

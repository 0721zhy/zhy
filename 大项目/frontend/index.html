图书管理系统

全栈课程项目：前端使用原生 HTML / CSS / JavaScript，通过 fetch 调用后端 RESTful 接口；后端采用 Node.js + Express（MVC 架构，端口 521），数据存储于 MySQL 数据库。服务器返回的数据与错误信息统一输出到浏览器控制台。

图书列表 查看全部图书，支持关键词搜索与分类筛选，可新增、编辑、删除图书。 图书详情 在列表中点击书名进入详情页，查看价格、库存、出版社等完整信息。 接口预览 直接访问 GET /api/books 查看后端返回的统一 JSON 格式（code / msg / data）。 数据库连接测试 输入 MySQL 用户名与密码，测试数据库连接是否可用，成功与失败均有提示。 科技新闻 新闻数据存放于 MySQL 表 zhang_news，列表页展示接口连接状态与新闻内容，支持搜索与分类筛选。 校园图文 图文数据存放于 MySQL 表 zhang_gallery，图片为本地文件，卡片式排列，点击可查看大图与完整说明。

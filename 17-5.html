17-5 · JavaScript 定时器

两种定时器：setTimeout 与 setInterval

JavaScript 通过 Window 对象提供两种定时器：setTimeout 在指定毫秒后执行一次，setInterval 每隔指定毫秒重复执行；它们分别用 clearTimeout / clearInterval 取消。下面通过两个互动演示体会区别。

一、两种定时器对比

对比项 setTimeout（一次性定时器） setInterval（周期性定时器）
执行次数 延时到达后只执行 1 次 每隔设定时间执行 1 次，循环往复
返回值 都返回一个整数编号（定时器 ID），用于取消
取消方法 clearTimeout(ID) clearInterval(ID)
典型场景 延迟提示、倒计时炸弹、防抖 秒表、轮播图自动播放、实时时钟
// setTimeout：3 秒后执行一次 var zhyT1 = setTimeout(function () { console.log('时间到！'); }, 3000); clearTimeout(zhyT1); // 在 3 秒内可取消 // setInterval：每 1 秒执行一次，持续重复 var zhyT2 = setInterval(function () { console.log('滴答'); }, 1000); clearInterval(zhyT2); // 停止重复执行

二、setTimeout 演示 · 3 秒倒计时炸弹

点击「点火」后启动一次性定时器，倒计时归零时"爆炸"；倒计时期间可随时用 clearTimeout 拆弹。

三、setInterval 演示 · 秒表

点击「开始」启动周期性定时器，每 50 毫秒刷新一次读数；「暂停」调用 clearInterval 停止，「计次」在运行中记录分秒。

00:00.00

说明：定时器回调由浏览器事件循环调度，延迟时间均为"不早于"设定值；页面切换到后台时浏览器可能降频，因此定时器不能保证精确时刻执行。

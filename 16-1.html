JS 数组方法 · 可视化演示

数组是最常用的数据结构。本页把数组画成带索引的方块条：绿色弹入 = 新增，黄色闪烁 = 命中，灰色划线 = 淘汰。每个方法都可点击运行，结果同步打印到 F12 控制台。

一、增删四方法 · push / pop / unshift / shift

push 尾部加、pop 尾部删（栈）；unshift 头部加、shift 头部删（队列）。除 push 外都返回被删的那个元素。

点击按钮试试，注意数组长度与索引的变化…

二、查找 · indexOf / includes

indexOf(x) 返回第一次出现的索引（找不到返回 -1）；includes(x) 只回答"有没有"（true / false）。命中的方块会黄色闪烁。

等待查找…

三、截取 · slice 与 splice 的区别

slice(1, 3) 是"复印机"——剪出副本，原数组不变；splice(1, 1, '…') 是"手术刀"——直接修改原数组，还能顺带插入。点击后对比两组数组条。

slice 组：原数组
splice 组：原数组

四、转换 · join / reverse / sort 排序的坑

join('→') 把数组连成字符串；reverse() 原地翻转。重点演示 sort 的坑：默认按字典序比较，[10,9,88,25].sort() 会得到 [10,25,88,9]——数字必须传比较函数！

五、迭代四剑客 · forEach / map / filter / reduce

以成绩数组 [88, 45, 92, 67, 73] 为例：forEach 逐个遍历；map 一对一加工出新数组；filter 按条件筛选（不达标划线降级）；reduce 滚雪球式累计。

记忆口诀：push/pop 管尾巴，unshift/shift 管脑袋；slice 复印不改原件，splice 动刀原数组变；map 加工、filter 挑拣、reduce 汇总。

﻿ 长度单位

Web 前端长度单位

CSS 中的长度单位分为绝对长度单位与相对长度单位两大类：绝对单位长度固定，相对单位会随字体大小或视口尺寸变化。

一、绝对长度单位

长度固定，不随浏览器窗口或字号变化，常用于打印场景。

单位名称换算关系说明
px像素基准单位网页开发中最常用，对应屏幕上的一个像素点
in英寸1in = 96px国际单位换算的基准
cm厘米1cm ≈ 37.8px常见于打印样式
mm毫米1mm ≈ 3.78px常见于打印样式
pt点1pt = 1/72in传统印刷单位
pc派卡1pc = 12pt印刷用，网页中较少使用

演示：px、in、cm、mm 的实际长度对比

96px
1in（= 96px，与上一行等长）
1cm
10mm

二、相对长度单位 · 相对于字体大小

随元素的字体大小或根元素字号变化，是最常用的相对单位。

单位参照对象说明
em当前元素的 font-size字号 24px 时，1em = 24px
rem根元素（html）的 font-size不受父级影响，适合整体缩放
%父元素的对应属性值如 width: 50% 即父元素宽度的一半

演示：em 与 rem 的区别（外层字号 32px，根字号 16px）

padding: 1em = 32px（跟随当前字号）
padding: 1rem = 16px（固定为根字号）

三、相对长度单位 · 相对于视口大小

随浏览器窗口（视口）尺寸变化，常用于响应式布局。

单位说明
vw视口宽度的 1%，如 100vw 表示铺满整行
vh视口高度的 1%，如 100vh 表示占满一屏
vminvw 与 vh 中较小的一个
vmaxvw 与 vh 中较大的一个

演示：调整浏览器窗口，观察两个盒子的变化

宽度 50vw
高度 25vh

vw 盒子只在窗口宽度变化时改变，vh 盒子只在窗口高度变化时改变。

四、其他常用相对单位

单位参照对象说明
ch当前字体中 "0" 字符的宽度常用于限制文本列宽，如 60ch
lh当前元素的行高（line-height）CSS 新增单位，便于按行高对齐
fr网格容器的等分份额仅用于 CSS Grid 布局，如 1fr 1fr 均分两列

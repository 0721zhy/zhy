"layzhang" 粒子文字动画

先把文字 layzhang 画在一张看不见的离屏画布上，再用 getImageData 采样文字像素点，每个采样点变成一颗淡紫色粒子。粒子从四面八方飞来，汇聚成文字；移动鼠标可以把粒子推开，松手后它们又会慢慢"愈合"。

一、动画演示

粒子 0 颗　·　点击画布打散再重聚

二、核心代码

// 1. 在离屏画布上绘制文字，采样像素生成粒子 zhyOffCtx.font = '700 180px "Microsoft YaHei"'; zhyOffCtx.fillText('layzhang', zhyX, zhyY); var zhyData = zhyOffCtx.getImageData(0, 0, zhyW, zhyH).data; for (var y = 0; y < zhyH; y += zhyGap) { for (var x = 0; x < zhyW; x += zhyGap) { if (zhyData[(y * zhyW + x) * 4 + 3] > 128) { // alpha 通道有字 zhyParticles.push({ x: 随机位置, y: 随机位置, tx: x, ty: y, // 目标 = 文字像素坐标 color: '#c8a8ff' }); // 淡紫色 } } } // 2. 每帧：粒子向目标缓动 + 鼠标斥力 zhyP.vx += (zhyP.tx - zhyP.x) * 0.02; // 弹簧引力 zhyP.vy += (zhyP.ty - zhyP.y) * 0.02; zhyP.vx *= 0.88; zhyP.vy *= 0.88; // 阻尼防震荡
说明：粒子颜色取自淡紫色系（#c8a8ff ~ #e6d9ff），在深紫夜色背景上呈现柔和光感；全部逻辑为原生 Canvas 2D，无第三方动画库。

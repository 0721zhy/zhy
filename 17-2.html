fetch 获取接口数据：随机狗狗图片

该接口允许跨域访问（响应头含 Access-Control-Allow-Origin: *），双击本页用 file:// 打开也能正常请求，是练习 fetch 的理想接口。

一、接口说明

GET https://dog.ceo/api/breeds/image/random
返回：{ "message": "图片URL", "status": "success" }
async function zhyLoadDog() { var zhyResp = await fetch('https://dog.ceo/api/breeds/image/random'); var zhyData = await zhyResp.json(); // 把 JSON 文本解析成对象 console.log(zhyData.message); // 图片地址 }

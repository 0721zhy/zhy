二、各层职责

层级组成职责
用户层PC 浏览器 / 移动 APP / 小程序三种入口访问同一套后端服务，前端页面只负责展示与交互
接入层CDN 加速 · Nginx 负载均衡 · API 网关静态资源就近分发；请求按负载分发到多台服务器；网关统一做鉴权、限流、路由
应用服务层用户 / 商品 / 购物车 / 订单 / 支付 / 物流 六大微服务按业务拆分，每个服务独立开发部署，通过接口互相调用
中间件层Redis 缓存 · RabbitMQ 消息队列 · Elasticsearch热点数据缓存削峰；下单等耗时操作异步解耦；商品搜索走全文检索引擎
数据层MySQL 主从集群 · OSS 文件存储交易数据持久化，主库写入、从库读取；商品图片等静态文件走对象存储
运维支撑监控告警 · 日志中心横切所有层：采集指标与日志，异常时自动告警

二、Canvas 绘制核心代码

// 节点用圆角矩形 + 文字绘制 function zhyDrawNode(zhyCtx, zhyNode, zhyHover) { zhyCtx.beginPath(); zhyCtx.roundRect(zhyNode.x, zhyNode.y, zhyNode.w, zhyNode.h, 8); zhyCtx.fillStyle = zhyNode.color; zhyCtx.fill(); zhyCtx.fillStyle = '#14202c'; zhyCtx.textAlign = 'center'; zhyCtx.fillText(zhyNode.name, zhyNode.x + zhyNode.w / 2, zhyNode.y + zhyNode.h / 2); } // 数据流光点：按 t∈[0,1] 在两点连线上插值移动 function zhyDrawFlow(zhyCtx, zhyX1, zhyY1, zhyX2, zhyY2, zhyT) { var zhyX = zhyX1 + (zhyX2 - zhyX1) * zhyT; var zhyY = zhyY1 + (zhyY2 - zhyY1) * zhyT; zhyCtx.beginPath(); zhyCtx.arc(zhyX, zhyY, 3, 0, Math.PI * 2); zhyCtx.fill(); }
说明：本图为教学示意图，全部节点与连线均为 Canvas 手写绘制，无任何第三方图表库；真实电商系统还会包含分库分表、服务注册中心、熔断降级等更多组件。

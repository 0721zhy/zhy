fetch 获取服务器数据

fetch() 是浏览器原生提供的网络请求接口，用于向服务器发送 HTTP 请求并获取响应。 它基于 Promise 设计，配合 async / await 可以写出清晰的异步代码。 本页面演示 fetch 的完整用法：发送请求、解析 JSON、处理加载状态、捕获错误、重新请求。

1. 点击按钮发起 fetch 请求

数据源是 data/students.json，模拟服务器返回的 JSON 格式。 本页面需要通过 http 服务器 打开（file:// 下 fetch 本地文件会被浏览器拦截）。

2. fetch 核心代码

点击按钮后实际运行的 JavaScript，带完整注释：

// fetch + async/await 典型写法
async function zhyFetchData(zhyUrl) {
    zhySetStatus('loading', '正在请求 ' + zhyUrl + ' ...');
    try {
        // 第 1 步：发送请求，拿到 Response 对象
        const zhyRes = await fetch(zhyUrl);

        // 第 2 步：检查 HTTP 状态码
        if (!zhyRes.ok) {
            throw new Error('HTTP ' + zhyRes.status);
        }

        // 第 3 步：把 Response 解析成 JSON
        const zhyData = await zhyRes.json();

        // 第 4 步：成功，渲染到页面
        zhyRenderData(zhyData);
    } catch (zhyErr) {
        // 第 5 步：捕获网络/解析/业务错误
        zhySetStatus('error', '请求失败：' + zhyErr.message);
    }
}

要点：
① fetch() 返回 Promise，await 后得到 Response 对象；
② res.ok 判断 HTTP 状态码是否在 200–299 之间；
③ res.json() 解析响应体为 JS 对象，也是异步的；
④ 两层异步：fetch → Response → json()，都需要 await；
⑤ catch 能捕获网络断开、404、JSON 格式错误等所有异常。

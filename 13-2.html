iconfont 图标（字体 + SVG 方式）

本页演示项目本地 iconfont 图标库的两种用法： ① 字体图标方式——引入 font/iconfont.css，用 <i class="iconfont icon-xxx"></i> 渲染，图标就是字体，可用 font-size / color 自由控制； ② SVG 方式——直接书写内联 <svg> 矢量标记，样式完全可控。 两种方式都不依赖任何第三方库或 CDN。

SVG 方式 · 手写内联矢量

SVG 图标的本质是一段内联矢量标记，不依赖字体文件，可直接书写。

Home 图标（24×24，描边式，stroke 随 color 变化）

手写 SVG 可直接在 <svg> 上设置 width、height、fill、stroke 等属性，实现完全可控的图标样式。

两种方式对比：
① 字体图标：引入一个 CSS 即可全站使用，类名调用最方便，适合导航、按钮等 UI 图标；
② SVG 方式：无字体文件依赖、支持多色与复杂图形，适合插画级图标；
③ 本项目统一使用 font/ 目录下的本地 iconfont 库，禁止引用第三方图标库与 CDN。
